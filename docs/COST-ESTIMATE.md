# Cost estimate

Indicative figures for the review. Not a quotation. Pilot commercial terms sit outside this repository.

| Item | Estimate | Note |
| --- | --- | --- |

LibreChat is not recommended inside this pilot. Decide after Zygm's AI overview. It would be a chat window beside this dashboard, not a replacement for ClickUp, Calendar, or Drive.
